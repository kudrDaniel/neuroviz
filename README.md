# 🧠 NeuroViz

**NeuroViz** — это инструмент для аудио-визуализации нового поколения. Вместо примитивных эквалайзеров он использует многослойный DSP-анализ (Digital Signal Processing), чтобы извлекать из музыки семантические события (удары, смену секций, высоту тона, стереопанораму), и транслирует их в визуальный движок для создания синестетического опыта.

Проект разделен на **Анализатор (Avalonia/C#)** и **Визуализатор (Godot/C#)**, которые общаются через высокоскоростной IPC-мост.

## ✨ Ключевые возможности

*   **Многоуровневый анализ:** От простых спектральных полос до предсказательного кодирования (поиск «сюрпризов»).
*   **Детекторы событий:**
    *   `Onset` (атаки, удары).
    *   `Novelty` (смены секций, новизна).
    *   `Pitch` (высота тона через HPS).
    *   `Azimuth` (стереопанорама через ILD).
    *   `Spectral Features` (гармоничность и центроид/яркость).
*   **Разделение Live и Replay:** Анализ происходит на лету, но результаты сохраняются в память, позволяя перематывать трек и видеть визуализацию заново без повторного анализа.
*   **Движок правил (JSON):** Позволяет гибко настраивать маппинг между событиями и параметрами визуализации.
*   **Изоляция процессов:** Если Godot упадет, инспектор продолжит работать.
*   **Debug-инспектор:** Встроенный просмотр спектрограмм и логов событий.

## 🏗 Архитектура

Проект состоит из следующих C#-проектов:

1.  **`NeuroViz.Core`** — Ядро. Схемы событий, контракты IPC, движок правил (RuleEngine).
2.  **`NeuroViz.Audio`** — Аудио-движок. Обертка над `ManagedBass`, извлечение PCM-сэмплов, аудио-клок.
3.  **`NeuroViz.Analysis`** — DSP. Спектрограмма (STFT), детекторы событий (Onset, Novelty, Pitch и др.).
4.  **`NeuroViz.Project`** — Сериализация. Сохранение таймлайнов и настроек в бинарный формат `.nvproj` (MessagePack).
5.  **`NeuroViz.App`** — UI. Инспектор на базе Avalonia (плеер, таблица событий, таймлайн).
6.  **`NeuroViz.Visualizer`** — Рендер. Проект Godot 4, который принимает параметры и рисует визуал.

### 📡 Как это работает (IPC)

1.  **Named Pipes** (`NeuroViz.Control` и `NeuroViz.EventStream`) передают команды управления и кадры событий/параметров от Avalonia к Godot.
2.  **Memory-Mapped File** (`NeuroViz.AudioClock`) используется для передачи точного времени воспроизведения (Audio Clock) без накладных расходов на сериализацию каждый кадр.

## 🛠 Требования

*   **.NET SDK** (8.0 или 10.0).
*   **Godot 4.x** (Обязательно версия **.NET** / Mono, обычная версия не подойдет).
*   **BASS Audio Library** (нативная библиотека).
    *   *Внимание:* Из-за лицензионных ограничений `bass.dll` не хранится в репозитории. Вам нужно скачать архив `bass24.zip` с [un4seen.com](https://www.un4seen.com/), извлечь `x64/bass.dll` и положить его в папку `src/NeuroViz.Audio/native/win-x64/`.

## 🚀 Быстрый старт

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/yourname/NeuroViz.git
    cd NeuroViz
2.  **Настройте BASS (Windows):**
    Убедитесь, что файл src/NeuroViz.Audio/native/win-x64/bass.dll существует (см. раздел Требования).

    Соберите решение:

    bash
    dotnet build
    Запустите Инспектор:

    bash
    dotnet run --project src/NeuroViz.App
Использование:

Нажмите Open... и выберите аудиофайл (wav, mp3, ogg, flac).

Нажмите Play (вы услышите звук и увидите события на таймлайне).

Нажмите Launch Visualizer. Откроется окно Godot.

Квадрат в Godot начнет реагировать на музыку.

Включите Debug Mode, чтобы видеть спектрограммы каждого события.

🎛 Настройка (Tuning)
Вся логика маппинга (какое событие на что влияет) вынесена в samples/rules/basic.json.
Вы можете менять min (минимальная уверенность), decayMs (время затухания) и связывать параметры на лету.

Подробное описание всех ползунков и настроек читайте в файле TUNING.md.
